**Project Title**
-----------------
**_Subscription Billing System_**

Project Description
-------------------
The Subscription Billing System is a Spring Boot based REST API project developed using Java, Spring Boot, MySQL, and JPA.

This project helps manage:
--------------------------
_Customers
_Subscriptions
Payments
Billing
Dashboard Analytics
Expired Subscriptions
The system automatically tracks subscription status and billing details.

Technologies Used
-------------------
Java 22
Spring Boot 3
Spring Data JPA
MySQL
Hibernate
Lombok
Maven
Swagger OpenAPI
IntelliJ IDEA
Postman
